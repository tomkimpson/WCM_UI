# CLAUDE.md

## Session handoff

If `handoff.md` and/or `log.md` exist at the repo root, read them at the start of the session:
- `handoff.md` — current status, open questions, blockers, next steps from the previous session.
- `log.md` — dated narrative of past sessions (newest at top). Skim the top entry for recent context, search deeper if you need to know what's already been tried.

Both are git-tracked, so they may lag the working tree. Treat as hints, not ground truth.
